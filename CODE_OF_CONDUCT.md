# Code of Conduct

## Purpose

This repository is publicly visible and maintained as a maintainer-operated
automation platform. The collaboration standards below apply to maintainers,
reviewers, and any current or future contributors.

## Expected Behavior

- Be respectful, patient, and specific.
- Focus reviews on evidence, behavior, and risk rather than personal judgment.
- Assume good intent and ask clarifying questions before escalating conflict.
- Keep security, privacy, and sensitive data concerns explicit.

## Unacceptable Behavior

- Harassment, abuse, or discriminatory language.
- Sharing secrets, personal data, or sensitive runtime artifacts in public
  channels or review threads.
- Personal attacks, hostile review language, or repeated bad-faith escalation.
- Pressuring others to hide failures, weaken gates, or misrepresent evidence.

## Scope

This code of conduct applies to repository-managed spaces, including issues,
pull requests, review comments, support exchanges, and related project
discussion channels.

## Reporting

- For conduct concerns, contact the repository maintainers through the same
  private support path documented in [SUPPORT.md](./SUPPORT.md).
- For security-sensitive behavior, use the private reporting path in
  [SECURITY.md](./SECURITY.md).

## Enforcement

- Maintainers may remove comments, close discussions, or restrict participation
  when behavior violates this code of conduct.
- Repeated or severe violations may lead to temporary or permanent loss of
  contribution access.
